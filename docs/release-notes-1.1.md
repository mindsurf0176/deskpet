# DeskPet 1.1

A macOS menu bar pet that reacts to coding agents, with window sitting, climbing,
completion captions, and click-to-focus for Orca and terminal sessions.

- Settings for size, language, tone, gravity, captions and sound.
- Completion actions persist while another agent starts working.
- Native Orca chats are located by provider session identity and their workspace is activated before tab selection.
- First launch without a pet now shows setup instructions.

Requires macOS 13 or later and a separately installed pet. Artwork is not bundled.
Agent hooks require the source installation described in the README.
